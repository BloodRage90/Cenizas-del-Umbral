# Evidencia de validación

Las capturas muestran el índice y el capítulo en 1280×720, 844×390, 667×375 y 390×844. También incluyen la arena lateral en horizontal móvil (844×390 y 667×375).

La comprobación se ejecutó con Chrome headless y Playwright: sin errores de consola, sin solicitudes fallidas y sin desbordamiento horizontal. La suite Node quedó en 33/33 pruebas y la matriz de identidad en 144/144 combinaciones.
