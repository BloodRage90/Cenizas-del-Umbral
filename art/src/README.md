# Fuentes de arte de protagonistas

Esta carpeta es el punto de entrada del pipeline de atlas. El arte definitivo
se incorporará como `art/src/<id>/combat.png` para cada id listado en
`docs/ART-BRIEF.md`. Mientras no exista aprobación, no se añaden aquí fuentes
inventadas: las hojas funcionales actuales viven en `dist/combat-heroes/` y el
manifiesto las marca como `PLACEHOLDER_ART_PENDING_APPROVAL`.
